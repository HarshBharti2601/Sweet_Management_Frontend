## Frontend Development

The frontend of this project was built using **Vercel v0**. I used prompt engineering to generate and refine UI components, layouts, and interactions efficiently.

By leveraging **Vercel AI tools**, I was able to quickly iterate on design ideas and convert them into a polished, production-ready interface. The result is an **aesthetically pleasing, well-structured, and user-friendly frontend** that complements the backend functionality effectively.

To explore more features such as purchasing, restocking, and admin-specific actions, please **log in to the application** using the deployed URL below.

### Live Deployment

- **Deployed Website:** https://sweetmanagementharshbharti.vercel.app/
- **Backend API URL:** https://sweet-management-for-harsh.vercel.app/
- **Backend GitHub Repository:** https://github.com/HarshBharti2601/Sweet_Management
